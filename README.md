# YOUR NAME - Personal Portfolio

A responsive personal portfolio website built with HTML, CSS and JavaScript and designed for deployment through GitHub Pages.

## Structure
- `index.html` - main portfolio page
- `css/style.css` - styling and responsive layout
- `js/script.js` - navigation interactions
- `assets/` - images, resume and certificates

## Deployment
1. Create a GitHub repository.
2. Push the project to the `main` branch.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch → main → /(root)**.
5. Save and open the generated GitHub Pages URL.

## Before submission
Replace the placeholder email, GitHub and LinkedIn URLs in `index.html`.
